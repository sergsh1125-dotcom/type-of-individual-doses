# 🛡️ Система обліку індивідуальних доз опромінення (ІДК)

Автоматизована інформаційно-аналітична система для ведення Журналу обліку індивідуальних доз зовнішнього опромінення особового складу (знідно з Додатком 3 до Методичних рекомендацій з ІДК) та аналізу накопичених доз за тривалі періоди спостереження (від 2 до 50 років).

## 📋 Основні можливості

- **Реєстр особового складу:** Ведення бази даних співробітників, їх посад, категорій опромінюваних осіб та року початку обліку.
- **Оперативне введення даних:** Швидке внесення разових вимірювань доз у мЗв із прив'язкою до дати.
- **Річний журнал (Додаток 3):** Автоматичне формування та консолідація доз за датами й розрахунок сумарної річної дози для кожного співробітника.
- **Багаторічний аналіз (2–50 років):** Обчислення накопиченої та середньорічної дози за довільно обраний часовий інтервал із побудовою інтерактивних графіків динаміки опромінення.
- **Пошук та фільтрація:** Гнучка система фільтрації за частковим збігом ПІБ, часовими інтервалами та пороговими значеннями отриманих доз.
- **Експорт даних:** Можливість вивантаження сформованих річних звітів у форматі CSV (сумісно з Excel).

## 🛠️ Технологічний стек

- **Мова програмування:** Python 3.9+
- **Веб-фреймворк:** Streamlit
- **Аналіз даних:** Pandas
- **База даних:** SQLite3 (автономна локальна БД)
